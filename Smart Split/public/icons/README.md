# Icons Directory

Place your PWA icon files here with the following names:
- icon-72x72.png
- icon-96x96.png
- icon-128x128.png
- icon-144x144.png
- icon-152x152.png
- icon-192x192.png
- icon-384x384.png
- icon-512x512.png

You can generate these icons using:
1. The `generate-icons.html` file in the public directory
2. Online tools like https://realfavicongenerator.net/
3. Or create them manually

For now, the app will work without icons, but they are required for a complete PWA experience.
